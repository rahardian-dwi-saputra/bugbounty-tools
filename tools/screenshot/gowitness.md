# gowitness
Tool ini digunakan untuk melakukan screen shot pada suatu halaman web

- Link download dan instalasi: https://github.com/sensepost/gowitness

## Instalasi
- Install menggunakan tool go
```sh
go install github.com/sensepost/gowitness@latest
```

- Copy ke folder `/usr/bin` supaya bisa digunakan dimana saja
```sh
sudo mv go/bin/gowitness /usr/bin
```
