# uro
Tool ini digunakan untuk menghilangkan url yang duplikat untuk menyederhanakn list URL

- Link download dan instalasi: https://github.com/s0md3v/uro

## Instalasi
- Update package
```sh
sudo apt update
```
- Install menggunakan pip3
```sh
pip3 install uro
```

- Copy folder hasil instalasi ke `/usr/bin` supaya bisa diakses dimanapun
```sh
sudo mv .local/bin/uro /usr/bin
```

- Dokumentasi cara penggunaan tool uro bisa dilihat dengan perintah berikut
```sh
uro -h
```
